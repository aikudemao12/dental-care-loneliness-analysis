# Dental-care disadvantage and loneliness

Analysis code and aggregate source data for *Life-course dental-care disadvantage and loneliness among adults aged 50 years and older: a 26-country cohort analysis*.

Version: `EJPH-R1-20261019-v3`.

- `analysis_code/scripts/`: input preparation and reported analyses.
- `source_data/`: aggregate tables supporting the manuscript and figures.
- `analysis_code/figures/`: final statistical figure renderer and editable Figure 1 diagram.

See `analysis_code/README.md` for analysis inputs and commands, and `analysis_code/figures/README.md` for figure export. This version synchronises the final figure sources; model specifications and numerical results are unchanged from v2.

Individual-level SHARE, CHARLS and KLoSA data must be obtained from their official providers under the applicable access conditions. They are not redistributed here. The MIT licence applies to the code.
